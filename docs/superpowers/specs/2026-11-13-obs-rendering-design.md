# OBS 显示精度优化

用户已同意先改参数修正、精确调节和描边对比预览。保留当前发光风格与两套独立配置；默认仍为阴影描边，原生描边作为可选对比方案。直接在当前 checkout 的新功能分支实现。

## Approaches

- 采用：共享文字效果计算，修复零值回退；真实 vh/行高数值、精细步进及最终像素估算；可调源尺寸、等比显示宽度、深浅背景、最终像素 1:1 与描边并排对比。
- 保留为用户操作：OBS 中对照 2 倍渲染尺寸和缩放滤镜；网页提供参考数值，不改写 OBS 配置。
- 暂不采用：替换为 SVG/Canvas 文字渲染。现有 DOM 换行、表情和渐变文字继续使用。

## Behavior

零发光、零投影必须真正关闭，预览与 OBS 共用计算。原生描边以两倍 CSS stroke 宽度保留现有外扩宽度概念，文字填充在描边之后，主播渐变保留独立底层。旧配置没有新字段时外观兼容。

设置面板输入真实值：字号/布局 0.01vh、描边/发光/投影 0.01vh、行高 0.05；保持原值，不在加载或显示时取整。尺寸元数据按模板保存，默认源尺寸 2400×3000，主样式显示宽度 820、缩小版 420；显示高度由源比例推导。源尺寸 16–8192，显示宽度 16–8192；无效值回退到合法值。

预览支持适应面板、最终像素 1:1（可滚动）、棋盘/深/浅背景。并排模式使用同一设置和尺寸，只改变描边方式。两倍渲染建议必须保持显示比例。说明 1:1 指网页 CSS 像素，最终清晰度仍需 OBS 实录核对。头像和表情使用 auto 图片缩放。

## 2026-11-15 描边与设置页改版

用户要求继续优化描边，并在保留原有功能的前提下美化设置页。采用浅色工作台：分类侧栏、独立模板切换、左侧编辑与右侧实时预览；保存与复制链接固定在页头，原有字体与备用字体、语言、颜色、布局、气泡、BLC 导入和测试工具继续可用。窄屏按单列布局呈现，折叠按钮提供 aria-expanded。

新增「清晰细描边」「圆润柔光」「高对比」三种预设，只修改用户名和弹幕的描边、发光及投影；不改字号、行距、颜色和尺寸。用户仍可分别微调两类文字。新增圆润阴影模式：增强模式三层圆环共 84 个采样、普通模式共 48 个，外圈分别 48/24 向；内圈用于避免粗描边在句号等窄字形旁留下空隙。原生、经典描边继续保留，旧配置不会自动改选预设。

预览工具重新排布，背景、并排对比和适应/1:1 查看属于预览状态；尺寸元数据置于折叠区。保存成功/失败使用不同颜色与图标的轻提示，失败后保留未保存状态。主样式与缩小版独立保存，切换模板及编辑在保存请求期间禁用。

### 第二轮描边细化

加密内外圆周采样，缓存单位圆坐标，避免每次生成样式重复三角运算。新增两类文字独立的 StrokeSoftness（vh）：只模糊圆润模式的描边阴影，不使用整层 filter，不改字面或主播渐变填充。柔化有效范围为 0 至 min(描边宽度×0.15, 0.08vh)，细描边缩小后自动限制有效值；缺失字段和显式 0 保持硬边。圆润柔光预设采用 0.025vh，高对比采用 0.01vh，清晰细描边采用 0；切换经典/原生模式时该参数不参与渲染。数值面板显示实际生效值并按最终显示尺寸估算像素。

## 2026-11-15 既有配置兼容

设置页的后端/浏览器缓存读取，以及实际 OBS 源的缓存/轮询读取，共用 normalizeObsSettings 和同一份默认设置。加载只构建内存对象，不自动提交配置；未知扩展字段保留，0、false、负间距和原有字体/行高/颜色保留。没有描边模式的配置使用经典阴影，缺少柔化字段时为 0；已有 native/smooth/shadow 选择保留，不自动应用预设。旧主配置缓存键 obsSettings 继续只给主模板使用，缩小版保持独立。

移除原先 usernameFontSize > 10 就猜为像素的缓存迁移。没有单位标记的既有配置按原 vh 值读取，即使字号超过编辑器上限，也不能推断其单位（旧 BLC 200px 导入结果为 15.7/18.5vh）。显式 obsSettingsUnit=px 才按旧 1080p 基准换算原文件存在的长度字段；缺失字段使用 vh 默认值，行高/字重等无单位字段不参与换算。规范化结果带 obsSettingsUnit=vh，用户保存后重复加载保持幂等。
